# export/

Everything `cad/build.py` writes, regenerated on each build. STL for the slicer, STEP for
CAD, 3MF where a part is laid in its printing pose.

| Folder | What is in it |
|---|---|
| [`device/`](device/) | Lid + base, the taped-in-phone build |
| [`plainnut/`](plainnut/) | Base for a plain DIN 934 nut |
| [`coupon21/`](coupon21/) | Hinge-station slice, to test before the full print |
| [`coupon-phone/`](coupon-phone/) | Lid's left end, to try the phone in: rib heights, button tongues |
| [`bezel/`](bezel/) | Lid for the clip-on frame and the frame; ribs and tongues here |
| [`switch/`](switch/) | Shuttle for the keyboard's power switch, 15 variants |
| [`switch-window/`](switch-window/) | Base with a window instead of the shuttle, and plugs |
| [`lid-variants/`](lid-variants/) | The whole bezel lid with rib heights 0.50 / 0.60 / 0.70 and tongues 0.8 / 1.0 / 1.2 |
| [`logo/`](logo/) | Logo recess lid and inlay |
| [`adapter/`](adapter/) | USB-C extender seat (parked) |
| `skladen2-2.1-plates.3mf` | Every 2.1 part laid out on plates in one Bambu project: 1 lid with logo, 2 frame, 3 base + plugs, 4 through-logo lid, 5 closed frame, 6-8 whole lids with different ribs and tongues |
