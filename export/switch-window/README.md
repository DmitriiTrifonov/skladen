# switch-window/

ADR-0014 (proposed, not printed): the power switch is reached by hand through a window in
the base's rear face, closed by a plug, instead of the printed shuttle in
[`../switch/`](../switch/). Take the plug out, push the knob with a toothpick.

| File | What it is |
|---|---|
| `skladen2-base-switchwindow.stl`, `.step` | Base with the window (9.4 wide in the wall, a 7.0 x 4.0 tunnel through the tail) |
| `skladen2-switch-plug-clr0.05.stl` | Plug, 0.05 mm clear on each side |
| `skladen2-switch-plug-clr0.10.stl` | Plug, 0.10 mm clear |
| `skladen2-switch-plug-clr0.15.stl` | Plug, 0.15 mm clear |

Print all three plugs and keep the one that goes in with a little push and stays. The
plugs print nipple-up. They are also on plate 3 of `../skladen2-2.1-plates.3mf`.
