# switch/

The shuttle from Mk3 that works the keyboard's slide switch from the rear face: a fork on
the knob, a stem through the tail, a thumb end in the rear face. The niche was never
measured, so this is a set to print and choose from.

Three folders by finger length (`finger0.5`, `finger1.0`, `finger1.5`, mm), five files
in each by how far the stem stands proud (`proud0.5` to `proud3.0`, mm). 15 STLs in all; each is in its printing pose.

Print the set, keep what works. ADR-0014 proposes dropping the shuttle for a window and
plug ([`../switch-window/`](../switch-window/)).

STL only, because the parts are only printed.
