# plainnut/

The same base as in [`../device/`](../device/), but with a shallower nut pocket for a
plain DIN 934 nut held with threadlocker, instead of the DIN 985 nylon nut. The lid is
shared with `device/`.

| File | What it is |
|---|---|
| `skladen2-base-plainnut.stl`, `.step` | Base, pocket 2.70 deep |
| `skladen2-coupon21-base-plainnut.stl`, `.step` | The hinge-station coupon of that base (see [`../coupon21/`](../coupon21/)) |

Regenerated by `cad/build.py`.
