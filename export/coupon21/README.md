# coupon21/

A slice of the right-hand hinge station (X 55 to 100), base and lid, to print and test
the hinge, the bolt and the nut before the whole device is printed. The base's slice
also carries the switch slot.

| File | What it is |
|---|---|
| `skladen2-coupon21-base.stl`, `.step` | Base slice (DIN 985 nylon nut) |
| `skladen2-coupon21-lid.stl`, `.step` | Lid slice |

The same slice with the DIN 934 pocket is in [`../plainnut/`](../plainnut/).

Regenerated by `cad/build.py`.
