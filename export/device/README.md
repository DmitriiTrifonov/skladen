# device/

The Skladen 2 as drawn in ADR-0004: lid + base, the lid holding the phone with tape on
the pocket floor. Nylon locking nut (DIN 985) in the base.

| File | What it is |
|---|---|
| `skladen2-base.stl`, `.step` | Base with the nut pocket for a DIN 985 nylon nut |
| `skladen2-lid.stl`, `.step` | Lid with the open button window, no logo, no crush ribs |

Not the bezel build: the lid for the clip-on frame, with ribs and button tongues, is in
[`../bezel/`](../bezel/). For a plain DIN 934 nut use the base in
[`../plainnut/`](../plainnut/) (the lid is shared).

Regenerated by `cad/build.py`.
