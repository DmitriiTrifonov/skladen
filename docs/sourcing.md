# Sourcing and references

Links found while looking for a cheaper source of the keyboard and for ideas for the
lid. Nothing here is verified against the physical Jomaa keyboard; the check is in
`docs/measurements.md`. Collected 2026-10-17.

## The Reddit build that prompted [ADR-0012](adr/0012-removable-front-bezel.md) and [ADR-0013](adr/0013-usbc-extender.md)

A Boox Palma in a printed clamshell with a bluetooth keyboard under it. A removable
front frame holds the phone, and a short USB-C adapter sits in a notch in the end wall.

- Video: <https://www.youtube.com/watch?v=iXehobjmJtI>
- The author's keyboards (Amazon short links, as given in the post):
  - Black, Doohoeek Universal Bluetooth Mini Keyboard: <https://a.co/d/6AUk5It>
  - Gray, CACOE Wireless Keyboard with Stand: <https://a.co/d/hjDWHji>
- The post says the keyboard's PU-leather case is glued on and peels off after warming
  the bottom with a hair dryer, as with the Jomaa.

## AliExpress search terms

- `foldable bluetooth keyboard PU leather case`
- `bluetooth keyboard folio case 7 8 inch`
- `mini folding bluetooth keyboard with stand`
- `Doohoeek keyboard`, `CACOE X62`

Pick listings that state dimensions and offer an RU layout, read the reviews with photos,
and buy one first. A second Jomaa is already on its way, so a second point of comparison
comes from that. Keep the FCC ID in mind: it names the real manufacturer, and none of the
sources above had it.
